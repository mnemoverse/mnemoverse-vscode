# Try it

In the agent chat, send a fact that is true, with your editor's name and today's date:

> Remember that I set up Mnemoverse memory in VS Code on 2026-09-23.

The **Try it** button fills in your editor and today's date for you.

Then open a **new** chat and ask:

> When and where did I set up Mnemoverse memory?

If the agent answers with that date and editor, memory is working. The memory stays with your Mnemoverse account: other tools you connect to Mnemoverse (Claude, Cursor, ChatGPT) read the same memories.

When a recalled memory helps or misleads, the agent can rate it (`memory_feedback`). Ratings change how memories rank in later searches.
