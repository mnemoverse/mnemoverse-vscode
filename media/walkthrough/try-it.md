# Try it

In the agent chat, send:

> Remember that I prefer Railway for deployments.

Then open a **new** chat and ask:

> Where should I deploy this?

If the agent answers Railway, memory is working. The memory stays with your Mnemoverse account: other tools you connect to Mnemoverse (Claude, Cursor, ChatGPT) read the same memories.

When a recalled memory helps or misleads, the agent can rate it (`memory_feedback`). Ratings change how memories rank in later searches.
